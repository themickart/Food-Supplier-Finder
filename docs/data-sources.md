# Источники и результат технической проверки

Дата документальной проверки: 24 октября 2026 года. Разрешённые расходы: 0. ИИ по последнему решению исключён из текущей версии.

## Что фактически подключено

- Серверный каталог: записи, вручную введённые со ссылкой на источник; источники не скачиваются автоматически.
- Отдельный вымышленный демонстрационный набор — исключительно для проверки интерфейса и сценариев.
- Автоматический внешний поиск: **не подключён**. Ответ API и интерфейс явно говорят об этом. Ручное добавление не засчитывается как автоматический поиск.
- ИИ и платные проверки: **не подключены**. Ключей в приложении нет, обращения к платным сервисам отсутствуют.

## Дополнительный бесплатный spike: OpenStreetMap / Overpass

24 октября 2026 выполнены реальные обращения без ключа, аккаунта и платежей. Источник — [Overpass API](https://overpass-api.de/api/interpreter), открытая база OpenStreetMap. [Правила публичного экземпляра](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html) описывают общие ресурсы, квоты, очереди и отказы 429/504; это не гарантированный SLA. [Лицензия данных](https://www.openstreetmap.org/copyright) — ODbL: требуется атрибуция и соблюдение условий распространения производной базы.

| Проверка | Результат |
| --- | --- |
| POST, именованные оптовые точки / пищевая промышленность в bbox Екатеринбурга, timeout сервера 12 с, максимум 15 результатов | HTTP 200; 3 объекта; измеренное полное время 28,56 с. В ответе — кондитерский оптовик, METRO и медицинский оптовик. Два потенциально food-релевантных объекта из трёх, без проверки готовности поставлять. |
| Короткий POST одного OSM-объекта с Origin локального preview, timeout клиента 18 с | ReadTimeout, 18,42 с. |
| Короткий GET одного OSM-объекта с Origin планируемого Pages, timeout клиента 15 с | ReadTimeout, 15,55 с. |

Тестовый запрос:

```text
[out:json][timeout:12][maxsize:16777216];
(
  nwr["shop"="wholesale"]["name"](56.7,60.4,56.97,60.85);
  nwr["industrial"="food"]["name"](56.7,60.4,56.97,60.85);
);
out tags 15;
```

В успешном ответе версия API `0.7.62.11`, срез базы `2026-10-24T01:40:11Z`. Временные сырые результаты находятся в игнорируемом `artifacts/overpass-*-spike.json`; в приложение и реальный каталог они не импортировались. Сохранено в каталоге: **0**, дедупликация внешней выдачи: **не проверена**, подтверждённых контактов: **0**. Наличие телефона в OSM не считается проверкой контакта по официальному сайту или звонком.

Решение: **не включать в текущую демонстрацию как работающий поисковый провайдер**. Нет устойчивого повторного ответа, CORS для браузера не подтверждён, полнота по трём целевым категориям/регионам не проверена. Геоданные об оптовых точках не равны полнотекстовому поиску поставщиков и не устанавливают их ассортимент/условия. Можно вернуться к этому кандидату как к отдельному ограниченному адаптеру после воспроизводимой проверки, классификации, CORS и лицензии экспортируемой базы. Ни один успешный запрос не подменяет подключение в приложении.

## Достоверность

Ручной контакт помечается «добавлен пользователем», не «проверен звонком». Цена должна относиться к товару, единице, фасовке и объёму; стоимость за упаковку не превращается автоматически в стоимость за кг. Документ требует ссылки. Отсутствующее значение остаётся «Не указано». Демонстрационные контакты/цены не являются фактами.

Проверка «поставщик реально действует и готов отгрузить» требует контакта с компанией. Её нельзя вывести из поисковой выдачи, сайта или ответа модели. Платная проверка реестров позднее должна стать отдельным адаптером с собственными источниками и датами, а не общим зелёным значком доверия.
